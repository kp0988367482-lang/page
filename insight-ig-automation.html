IG 留言自動發送 Notion 系統

ManyChat + n8n + Notion - 留言觸發，自動 DM 內容連結
- 返回 SEOULMATE 31

一、完整自動化流程

1

IG 貼文留言

用戶在貼文留言指定關鍵字，例如「加油」、「模板」、「資源」。

2

ManyChat Keyword Trigger

ManyChat 偵測到關鍵字，觸發 Automation，呼叫 External Request（Webhook）。

3

n8n Webhook 接收

n8n 接收 ManyChat 傳來的 username、user_id、comment 等資料，開始 Workflow。

4

Notion 建立頁面

n8n 呼叫 Notion API，在指定 Database 建立新頁面，填入整理好的內容。

5

取得 Notion 連結

Notion API 回傳 page url，n8n 將連結傳給 ManyChat API。

6

Instagram DM 發送

ManyChat 自動發送私訊給留言者，訊息包含 Notion 頁面連結。

二、ManyChat 設定教學

步驟

建立 Instagram Comment 觸發

  1. 進入 ManyChat 後台 - Automation - Instagram Comments
  2. 建立新規則，Trigger Type 選 Keyword
  3. 輸入關鍵字（如：加油、模板、資源）
  4. 新增動作：External Request
  5. 填入 n8n Webhook URL
關鍵：DM 訊息只需發送連結，不要塞入大量文字，避免被 IG 標記為垃圾訊息。

三、n8n Webhook 資料格式

ManyChat 呼叫 Webhook 時，傳送的資料結構如下：

{
  "username": "user123",
  "user_id": "1789xxxx",
  "comment": "加油"
}

n8n 回傳 ManyChat 發送 DM 的 API 呼叫：

POST https://api.manychat.com/fb/sending/sendContent

{
  "subscriber_id": "1789xxxx",
  "message": {
    "text": "這是您要的內容：https://notion.so/xxxxx"
  }
}

四、Notion 頁面模板結構

Notion Page 建議格式

標題：資源名稱 / 教學名稱

  • 內容簡介 - 一段說明這份資源的用途
  • 重點整理 - 3-5 個核心重點（條列）
  • 操作步驟 - 從頭到尾的操作流程
  • 使用工具 - 工具名稱 + 用途表格
  • 延伸資源 - 相關連結或模板
